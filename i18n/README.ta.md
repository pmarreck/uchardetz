# uchardetz

[uchardet](https://github.com/BYVoid/uchardet) (Mozilla-விலிருந்து மாற்றப்பட்ட குறியீடு கண்டறிதல் நூலகம்) திட்டத்தின் ஒரு கிளை (fork), **Zig கட்டமைப்பு அமைப்பு** ஆதரவுடன்.

## Zig கட்டமைப்பு

இந்த கிளை `build.zig` மற்றும் `build.zig.zon` கோப்புகளைச் சேர்க்கிறது, இதன் மூலம் நூலகம், பகிரப்படும் நூலகம், CLI கருவி, மற்றும் சோதனைகள் அனைத்தையும் Zig கட்டமைப்பு அமைப்பு (0.15+) மூலம் கட்டமைக்க முடியும். இது Zig திட்டங்களில் சார்புநிலையாகப் பயன்படுத்துவதையும், Zig ஆதரிக்கும் எந்த இலக்குக்கும் குறுக்கு-தொகுப்பு செய்வதையும் எளிதாக்குகிறது.

### Zig மூலம் கட்டமைத்தல் (Nix வழியாக)

```bash
# Dev shell-ல் நுழையுங்கள் (Zig 0.15 மற்றும் macOS SDK வழங்குகிறது)
nix develop

# எல்லாவற்றையும் கட்டமையுங்கள் (நிலையான நூலகம் + பகிரப்படும் நூலகம் + CLI)
zig build

# CLI-ஐ இயக்குங்கள்
zig build run -- somefile.txt
echo "some text" | ./zig-out/bin/uchardet

# சோதனைத் தொகுப்பை இயக்குங்கள்
zig build test
```

### Nix மூலம் நேரடியாகக் கட்டமைத்தல்

```bash
nix build
# வெளியீடுகள்: result/bin/uchardet, result/lib/libuchardet.{a,dylib}, result/include/uchardet/uchardet.h
```

### Zig சார்புநிலையாகப் பயன்படுத்துதல்

உங்கள் `build.zig.zon`-ல் சேர்க்கவும்:

```zig
.dependencies = .{
    .uchardetz = .{
        .url = "https://github.com/pmarreck/uchardetz/archive/<commit>.tar.gz",
        .hash = "...",
    },
},
```

பிறகு உங்கள் `build.zig`-ல்:

```zig
const uchardetz_dep = b.dependency("uchardetz", .{
    .target = target,
    .optimize = optimize,
});
your_module.linkLibrary(uchardetz_dep.artifact("uchardet"));
```

## வெளியீடுகள்

- **`libuchardet.a`** — நிலையான நூலகம்
- **`libuchardet.dylib`** (அல்லது `.so`) — பகிரப்படும் நூலகம்
- **`uchardet`** — CLI கருவி
- **`include/uchardet/uchardet.h`** — பொது C தலைப்புக் கோப்பு

## Upstream-க்கு மேலான திருத்தங்கள்

Upstream 5 சோதனைகளை "அறியப்பட்ட பிழைகள்" எனத் தவிர்த்தது. இந்த கிளை அனைத்தையும் சரிசெய்கிறது (60/60 வெற்றி, 0 பின்னடைவுகள்). எதுவும் கண்டறிதல் வழிமுறையின் அடிப்படைக் குறைபாடாக இருக்கவில்லை — ஒவ்வொன்றுக்கும் இலக்கான திருத்தம் இருந்தது.

| சோதனை | திருப்பிய மதிப்பு | மூல காரணம் | திருத்தம் |
|--------|-------------------|------------|----------|
| `da/iso-8859-1` | `ISO-8859-15` | ஒரே மாதிரியான நம்பிக்கை மதிப்பெண்கள்; ISO-8859-15 prober முதலில் இயங்கி, சமநிலையில் வெற்றி பெற்றது | டேனிஷ் prober வரிசையை மாற்றி, ISO-8859-1 (பழமையானது, அதிகம் பயன்படுத்தப்படுவது) சமநிலையில் வெற்றி பெறச் செய்தோம் |
| `da/iso-8859-15` | *(தவிர்க்கப்பட்டது)* | பைட் `0xA4` (8859-15-ல் யூரோ குறியீடு, 8859-1-ல் நாணயக் குறியீடு) இரு மாதிரிகளிலும் `SYM` எனக் குறிக்கப்பட்டிருந்தது, எனவே மதிப்பெண்கள் ஒரே மாதிரியாக இருந்தன | ISO-8859-1 வரைபடத்தில் `0xA4` ஐ `ILL` எனக் குறித்தோம் — நாணயக் குறியீடு (¤) உண்மையான உரையில் கிட்டத்தட்ட பயன்படுத்தப்படுவதில்லை. `0xA4` தோன்றும்போது, 8859-1 prober இப்போது விலகி, 8859-15 வெற்றி பெற அனுமதிக்கிறது |
| `es/iso-8859-15` | `ISO-8859-1` | டேனிஷ் போன்ற அதே `0xA4` தெளிவின்மை | அதே `ILL` திருத்தம் ஸ்பானிஷ் ISO-8859-1 வரைபடத்தில் பயன்படுத்தப்பட்டது (பிரெஞ்சு மற்றும் ஜெர்மன் வரைபடங்களிலும் முன்னெச்சரிக்கையாகப் பயன்படுத்தப்பட்டது) |
| `he/iso-8859-8` | `WINDOWS-1255` | **சோதனைத் தரவே தவறாக இருந்தது.** இது தர்க்கரீதியாக வரிசைப்படுத்தப்பட்ட எபிரேயத்தை (சொற்களின் முடிவில் இறுதி-வடிவ எழுத்துகள்) கொண்டிருந்தது, இதை prober சரியாக Windows-1255 எனக் கண்டறிகிறது. ISO-8859-8 என்பது *காட்சி* குறியீடு | சோதனைக் கோப்பை காட்சிரீதியாக வரிசைப்படுத்தப்பட்ட எபிரேயத்துடன் (வரிகளுக்குள் பைட்-தலைகீழ் தொடர்கள்) மாற்றினோம், இது இறுதி-எழுத்து பகுப்பாய்வுக்கு தெளிவான காட்சி-வரிசை சமிக்ஞையை அளிக்கிறது |
